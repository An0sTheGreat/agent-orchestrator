# Vendor icons

The PNGs in this folder are the model makers' and services' logos shown beside model ids on the Remote API page.

- Source: [LobeHub Icons](https://github.com/lobehub/lobe-icons), npm package `@lobehub/icons-static-png` version 2.6.0
  (git commit 6e2e41d2968d15755e3d4a75046483a34b9f7bf7), the `light` folder, fetched 2026-11-05 from
  https://unpkg.com/@lobehub/icons-static-png@2.6.0/
- Changes: scaled from 640x640 to 64x64. Files named `-color` keep their colours; the app draws the others in the
  theme's text colour.
- Trademarks: the logos are trademarks and property of their respective owners. They are used here only to identify
  which company or service makes a model, and imply no affiliation or endorsement. The LobeHub license below covers the
  icon set; it does not grant rights to the marks themselves (the lobe-icons README states no trademark terms).
