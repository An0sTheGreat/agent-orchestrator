# /research

## Purpose
Research a technical question with the in-app browser and answer with cited sources.

## Rules
- Search before answering when current or external facts matter.
- Prefer primary sources: official docs, repositories, standards, release notes.
- Use a few strong sources instead of many weak ones.
- Open relevant pages; use page search/find when useful.
- Separate sourced facts from inference.
- Never invent citations.

## Workflow
1. Turn the request into one clear research question.
2. Search for 2-5 relevant sources.
3. Open the strongest sources.
4. Find the exact sections that answer the question.
5. Compare conflicting information if present.
6. Answer directly with citations near the claims.
7. End with a short source list if the app supports it.

## Output
### Answer
<concise sourced answer>

### Key Evidence
- <fact> - <citation>
- <fact> - <citation>

### Sources
- <title/link or app citation>

## Stop Conditions
If reliable sources disagree, say so and explain the disagreement instead of choosing silently.
